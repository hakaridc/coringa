Sobre o Projeto

Este site foi desenvolvido como projeto acadêmico da disciplina de Programação Web / Desenvolvimento de Sistemas. O objetivo principal é criar uma aplicação completa utilizando as tecnologias estudadas em sala de aula.

Objetivo

Desenvolver um sistema com páginas de cadastro, login e área do usuário, aplicando conceitos de front-end e integração com backend em linguagem C.

Tecnologias Utilizadas

HTML5
CSS3
Linguagem C

Funcionalidades

  • Página inicial com navegação
  • Formulário de cadastro de usuários
  • Sistema de login
  • Página de contato
  • Área do usuário (Dashboard)
